# Patterns: I-9 wizard

Runnable code first. `helpers/i9.ts` and `helpers/i9-flow.ts` are the executable pattern
library for this area; the specs under `tests/employee/i9/` are complete walkthroughs.
Reach for these before hand-driving the page; fall back to step-by-step only for
exploring something new. The notes below exist only where the code needs context.

## Step synchronization
The wizard has no per-step URLs. Sync on the step headings with `expectStep`
(`helpers/i9-flow.ts`, `STEP` map). After clicking Next, wait for the next heading, not
for network idle.

## Signature pad (canvas)
Draw a real mouse stroke relative to the canvas bounding box: `drawSignature`
(`helpers/i9-flow.ts`) or `signForm` (`helpers/i9.ts`). Fixed-coordinate clicks break on
mobile viewports, and a single dot may not register (see fragile-spots, 2026-07-30).

## Date fields
Fill `input[name="expiration_date"]` directly with `MM/DD/YYYY` (`12/31/2030` is the
suite's standard future date). Do not drive the datepicker popup (see fragile-spots,
2026-07-30).

## vue-multiselect (state, issuing authority)
Not a native select. Use `selectWbMultiselect` (`helpers/i9-flow.ts`): click the
`.multiselect`, wait, click the first `li[role="option"]`. Disabled or prefilled
instances count as handled.

## File uploads
`setInputFiles` on `input[type="file"]` with `data/IMG_5733.jpg`, then wait for the
`Remove` button count to confirm the upload processed (up to 30 s). See
`uploadPassportImages` (`helpers/i9.ts`) and `fillAttachment` (`helpers/i9-flow.ts`).

## Document selection
Options are `.document-option[data-key="..."]`. Selected state is the `active` class;
ineligible options carry `disabled`. See `selectDoc` and `openListsBC`.

## Entering the wizard is flaky
`startI9` retries up to 3 times because starting a resubmission can land on a stale 404
(see fragile-spots). Reuse `startI9`; do not re-implement wizard entry.

## End-to-end walkthroughs (runnable)
- Happy path, citizen with US passport, submits for real:
  `npx playwright test tests/employee/i9/i9-happy-path.spec.ts --project=chromium --workers=1`
- Any citizenship and document combination, up to the signature step:
  `fillFormForDocs` (`helpers/i9-flow.ts`); complete with `finishWithSignature`.
